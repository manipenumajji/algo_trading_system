# AI Algorithmic Trading System

## Overview
This project is being built to develop an AI-driven algorithmic trading system capable of analyzing financial markets and automating trading decisions.

## Goals
- Market data analysis
- AI-based predictions
- Backtesting engine
- Risk management
- Live trade execution

## Tech Stack
- Python
- Pandas
- NumPy
- Machine Learning
- FastAPI
- PostgreSQL

## Project Structure
- data/ -> datasets and market data
- docs/ -> project documentation
- notebooks/ -> experiments and analysis
- src/ -> source code
- tests/ -> testing
